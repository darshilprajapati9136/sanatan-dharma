# Information Architecture

# 1. Purpose

The Information Architecture defines the structure of the Sanatan Dharma platform.

Its purpose is to make sure users can easily:

- Understand what the website offers
- Find trustworthy information
- Learn in a structured sequence
- Browse scriptures
- Explore deities, festivals, mantras, and concepts
- Ask questions using AI
- Save and revisit useful content
- Switch between English and Hindi

The website should be simple enough for beginners while still allowing deeper exploration.

1. Learn
1. Scriptures

Secondary navigation:

# 47. Architecture Principle

The platform should not behave like Wikipedia with disconnected pages.

It should behave like a **guided knowledge network**.

A user should be able to move naturally from:

**Question ****→**** Explanation ****→**** Scripture ****→**** Verse ****→**** Concept ****→**** Tradition ****→**** Related learning**

without becoming lost.

This interconnected structure should become one of the core strengths of the product.
